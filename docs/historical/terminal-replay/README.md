# Archived terminal replay captures

These original JSON histories and manifest are preserved byte-identically from the retired terminal/coding product. They refer to deleted legacy workflows, activity names, sample projects and capture commands. They are **not executable replay tests for WebChatSessionWorkflow** and make no current compatibility/migration promise.

The old capture utility depended on the retired sample/coding stack and was removed. New web unit and isolated integration tests cover Continue-As-New, recorded approval, parallel/child work, cancellation joining and process restart. Those are new-runtime evidence, not compatibility with these captures. No `.data/` or user artifacts were deleted by retirement.
