# Operations

The supported product is the local browser application. Follow [web-chat operations](web-chat-operations.md) for prerequisites, `mise trust`, setup/up/down, exact model qualification, process/container ownership, logs, SQL+attachment backup and safe restart.

The terminal/coding product has been retired. Historical terminal documentation and replay captures are not executable instructions for this runtime and do not promise legacy workflow or data migration. Default commands never delete `.data/`, volumes, originals, models or uncertain orphan artifacts.
